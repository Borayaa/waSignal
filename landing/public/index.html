From chat message to open position

Four steps, no copy-pasting, no staring at your phone.

  1. Connect WhatsApp or Telegram

    Link WhatsApp Web or Telegram through the bridge, then pick the one chat, group, or channel to follow. Everything else is ignored. You can use WhatsApp, Telegram, or both at once, each with its own target.

  2. AI extracts the trade

    Each message becomes structured JSON: side, symbol, order type, entry, stop loss, take profits and lot.

  3. Safety checks

    The trade must pass every rule you set before it can reach your broker. Anything doubtful is rejected.

  4. Executes on cTrader

    The order goes to your IC Markets cTrader account through the official Open API in about a second.

Built to say no

A misread message should cost you nothing. These checks run before anything trades.

Confidence threshold

Low-confidence extractions are dropped, not guessed at.

Prices must be in the message

Every price has to appear literally in the original text, so the model cannot invent numbers.

Sides must make sense

Stop loss and take profit have to sit on the correct side of entry for a buy or a sell.

No silent conversions

A pending order without an entry price is rejected. It is never turned into a market order.

Stale messages ignored

Messages older than 5 minutes are skipped.

Symbol allow-list and mapping

Only symbols you allow can trade. Map names like GOLD to XAUUSD.

Lot and position caps

Set a maximum lot size and a maximum number of open positions.

Dry-run mode

See what would have been traded without sending a single order.

Off until you switch it on

Automation is disabled by default on every new workspace.

Questions

Which brokers work?

InfraGreen executes on cTrader, currently with IC Markets, through the official cTrader Open API.

Does it need my trading password?

No. You connect with your cTrader ID using OAuth, and the app never sees your trading password.

Can I test it safely?

Yes. Use a demo account, and turn on dry-run mode to see what would be traded without placing orders. The playground lets you test messages too.

Which chats does it read?

Only the single WhatsApp chat or group you select, through a WhatsApp Web bridge.

What does it cost to run?

Because it runs serverless on Cloudflare, running costs are typically very low and may fit within Cloudflare's free tier, depending on your usage. The dashboard includes a running-cost view.

How do I get an account?

Access is by invite code. Email hello@infragreen.app to request one.

Does it work with Telegram channels?

Yes. Telegram signals come through your own user session (like Telegram Desktop), not a bot, so any channel or group you have joined can be the signal source. Your Telegram credentials are never stored; the session is managed securely in the bridge.
